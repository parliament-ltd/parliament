Alarms, v1

The timer you asked for, as a board of alarms. Three kinds, each set from the bar or with the plus: a timer (alarm:25m), a time of day (alarm:15:30), and a break every so often while you work (alarm:every 50m). An alarm rings in Parliament's tab, and outside it if you allow that. Nothing leaves this computer.

A browser can only ring while a Parliament tab is open: there is no server to wake it, by design. The board says so where it matters.

1 · The board

Each alarm a row, the next to ring first: its name, when, and the time left, counting down while the board is on the screen. The switch turns one off without losing it.

The browser's own notice. Asked for the first time you set an alarm, never before; "no" is fine, and it rings in the tab as above.

  • With several Parliament tabs open, one rings; the others hear that it did by its id alone, as tabs tell each other now.
  • The chime can be turned off in Settings, or with alarm:quiet; the band and the title still show.

4 · What a browser allows, and how it is kept light

  • Only while a tab is open. Closed, nothing rings: there is no server to wake the page, and no notice can be scheduled ahead. Opened again after the time, the alarm shows as rung, saying when.
  • Set by the clock, not counted. A browser slows timers in a tab out of sight, so each alarm is the time it rings, checked again whenever the tab is seen. Out of sight, it rings on time or up to a minute late. A computer asleep rings when it wakes, and says how late.
  • One timer. Only the next alarm waits; the board counts down once a second, and only while it is on the screen. The board's code loads the first time it opens.

6 · To rule

  1. The board and its three kinds: a timer, a time of day, a break every so often while you work.
  2. Breaks count work, not the clock: away ten minutes or more and the count starts over.
  3. Ringing: a band over the bar with a chime, the tab's title, and the browser's notice if allowed, asked on the first alarm.
  4. In Focus too, and the chime turned off in Settings or with alarm:quiet.
  5. The strip shows the next one: "Alarms: 03:12".
  6. Stored as above, in the settings, on this device; breaks in a backup or not.
