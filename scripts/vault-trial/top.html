Vault storage trial

The page is here; the vault is the frame below, on another address of the same site. Run node scripts/vault-trial/server.mjs, then:

  1. Write. A test value goes into the vault's storage.
  2. Reload this page and Read: the value should still be there.
  3. Open this page in a second tab and Read: the same value.
  4. Open the vault on its own: it should show the same value (its storage is not split off for being framed).
  5. The control: open this page from a different site and Read: it should show nothing, since a different site gets the vault's storage split off.
  6. Close the browser, open this page again, Read: still there.
